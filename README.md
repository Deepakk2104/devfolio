# Devfolio

Personal portfolio of **Deepak Kumar** — Full Stack Developer.

Built from scratch with Next.js, React, TypeScript, and Tailwind CSS v4.

## Sections

- **Hero** — name, role, summary, quick links
- **Skills** — categorized tech stack
- **Projects** — Orbit, RankPilot, Learnify (code + live demos)
- **Experience** — Frontend Developer Intern at Spearmint Technologies
- **Contact** — email, phone, GitHub, LinkedIn

## Stack

- Next.js (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- lucide-react / react-icons
- Light & dark mode (system-aware)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production Build

```bash
npm run build
```

## Data

All portfolio content lives in `src/data/resume.ts` — update it to change the site without touching components.
